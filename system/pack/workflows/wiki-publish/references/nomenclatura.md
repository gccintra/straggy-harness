# Nomenclatura das páginas de wiki (padrão do pack)

Convenção default de título. A organização sobrescreve este arquivo em
`org/workflows/wiki-publish/references/nomenclatura.md` quando usa outra.

| Conteúdo | Título |
|---|---|
| Módulo do produto | `Módulo — [Nome]` |
| Fluxo | `Fluxo — [Nome]` |
| Changelog | `Changelog — Histórico de Evolução` (página única, append) |
| Decisão técnica | `Decisão — [Tema]` |
| Glossário | `Glossário — [Área]` |

Título fora da convenção → proponha o título ajustado antes de publicar; quem decide é o
usuário.
