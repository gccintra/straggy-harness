## Apresentando ao cliente

O botão flutuante no canto inferior direito abre o painel de cenários da tela atual.

- Tecla `P` faz o botão sumir ou voltar. O clique no botão abre a lista. O atalho não dispara com o foco em um campo editável.
- O cabeçalho mostra a tela atual; o botão mostra o estado ativo, com um ponto quando a tela saiu do padrão. "Voltar ao padrão" limpa tudo.
- "Ir para outra tela" lista todas as telas do protótipo, agrupadas — dá para conduzir a demo sem passar pelo menu.
- Cada opção grava a query da URL (ou abre outra rota). O link continua sendo a fonte da verdade: dá para abrir o mesmo cenário direto na barra de endereço.
- A seção de perfil (ou outra dimensão global) só aparece quando o projeto a declara.
- O painel não entra em captura (`?export=1`), em automação nem na impressão.
