# Procedimento padrão — gerenciar sprint (pack)

Passo a passo default da ação `gerenciar-sprint`. A organização sobrescreve este arquivo em
`org/workflows/sprint-ops/references/procedimento.md`.

## Cadência default

Duração fixa, definida uma vez e mantida — sprint que muda de tamanho a cada ciclo não gera
base de comparação. A seguinte abre no dia em que a anterior fecha.

## Abrir

A sprint nasce com nome no padrão das anteriores, data de início e fim, meta e escopo.
Sprint aberta sem meta é uma lista de tarefas com prazo.

## Fechar

O fechamento produz, antes de qualquer alteração: o que foi entregue, o que não foi, e o
destino de cada item não entregue — volta para a fila, vai para a próxima sprint, ou é
descartado. Fechar a sprint não encerra as demandas que estavam nela.

## Mover em lote

Movimentação em lote é sempre sobre uma lista nomeada, nunca sobre "o que sobrou". Item
movido em duas sprints seguidas é sinal a reportar, não rotina.
