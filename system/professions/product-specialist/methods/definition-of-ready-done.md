# Definição de pronto para começar e de entregue

## Quando usar / quando não

- Use quando itens entram no ciclo sem contexto, ou quando "pronto" significa coisas
  diferentes para cada pessoa.
- Não use como instrumento de cobrança individual.

## Barra de qualidade

- **Acordo do time**, não imposição do PO — critério que o time não reconhece é ignorado na
  prática.
- Curto o bastante para ser lembrado sem consultar. Lista longa vira burocracia e é
  contornada.
- "Entregue" inclui o que é preciso para o usuário efetivamente usar (dado migrado,
  comunicação, permissão), não só código em produção.
- Exceção acontece: quando acontecer, é registrada com o motivo, não normalizada em
  silêncio.

## Contrato de output

Critérios de entrada (o que um item precisa para ser planejado) · critérios de saída (o que
precisa para ser dito entregue) · onde ficam publicados e quando foram acordados.
