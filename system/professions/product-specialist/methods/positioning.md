# Posicionamento

## Quando usar / quando não

- Use para alinhar a que público o produto serve, contra que alternativa ele compete e qual
  é o diferencial defensável — antes de mensagem, nome de categoria ou página de venda.
- Não use para decidir escopo de sprint.

## Barra de qualidade

- Público **específico o bastante para excluir alguém**. "Todo mundo" não é posicionamento.
- Alternativa real citada, inclusive processo manual e não fazer nada.
- Diferencial verificável com prova (dado, capacidade, restrição do concorrente), nunca
  adjetivo.
- A posição obriga a abrir mão de algo — se não custa nada, não é escolha.

## Contrato de output

Para <público> que <necessidade>, <produto> é <categoria> que <benefício>; diferente de
<alternativa> porque <prova>. Mais: o que essa posição obriga a **não** fazer.
