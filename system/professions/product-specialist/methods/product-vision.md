# Visão de produto

## Quando usar / quando não

- Use quando o time não sabe para onde vai além do próximo trimestre, ou quando toda
  discussão de escopo vira negociação sem referência.
- Não use como meta: visão é destino e não tem data de conclusão.

## Barra de qualidade

- Descreve o **mundo mudado** para o usuário, não a lista de funcionalidades.
- Suficientemente concreta para excluir caminhos — visão que aceita qualquer roadmap não
  orienta nada.
- Estável por anos; se muda a cada trimestre, era meta disfarçada.
- Compreensível por quem é de fora, sem jargão interno.
- Ligada ao presente: qual é a primeira coisa que já caminha para lá.

## Contrato de output

Visão em poucas frases (para quem, que mundo, por que importa) · o que ela exclui · o
primeiro passo já em curso.
