# Nível de lançamento

## Quando usar / quando não

- Use para decidir o alcance da liberação: interno, grupo fechado, gradual ou geral.
- Não use como forma de adiar decisão — beta eterno é entrega que ninguém assume.

## Barra de qualidade

- Nível escolhido pelo **risco e pela incerteza**, não pela ansiedade do calendário.
- Cada nível com critério de entrada e de saída declarados: o que precisa estar verdadeiro
  para ir ao próximo.
- Grupo fechado tem propósito de aprendizado definido; se ninguém vai ler o feedback, não é
  beta, é atraso.
- Comunicação proporcional: liberar em silêncio algo que muda a rotina do usuário gera
  suporte, não elogio.
- Data de revisão marcada em qualquer nível intermediário.

## Contrato de output

Nível escolhido com justificativa · critério para avançar e para recuar · quem participa ·
data de revisão.
