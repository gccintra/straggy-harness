# Plano de entrega

## Quando usar / quando não

- Use quando várias entregas dependem umas das outras, ou existe data externa real (evento,
  contrato, obrigação legal).
- Não use para criar data por item onde não há compromisso externo.

## Barra de qualidade

- Cada marco entrega uma **fatia usável**, não uma camada técnica.
- Dependência externa com dono e data acordada — "estamos aguardando" não é plano.
- Caminho crítico identificado; atraso nele é atraso do plano, o resto tem folga.
- Folga explícita. Plano sem folga não sobrevive ao primeiro imprevisto.
- Variável de ajuste combinada antes: quando aperta, o que cede é escopo — nunca qualidade,
  e a data só quando não é contratual.

## Contrato de output

Marcos com fatia entregável · dependências com dono e data · caminho crítico · variável de
ajuste acordada · riscos com plano de contorno.
