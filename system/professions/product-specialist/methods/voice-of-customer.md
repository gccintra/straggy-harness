# Voz do cliente — de feedback disperso a padrão

## Quando usar / quando não

- Use quando há massa de feedback (chamados, pesquisas, entrevistas, conversas de venda) e
  é preciso extrair padrão.
- Não use quando a pergunta é quantitativa sobre uso do produto — isso é métrica
  (`product-metrics.md`), não feedback.

## Barra de qualidade

- Agrupamento **por problema**, nunca pela solução que o cliente pediu.
- Cada tema com frequência, severidade e segmento — sem isso, ranking é impressão.
- Citação literal preservada como âncora de cada tema.
- Distingue "quem reclamou mais alto" de "quantos são afetados"; cliente grande não vira
  maioria.
- Contradição entre fontes é reportada, não resolvida em silêncio.

## Contrato de output

Temas ranqueados (frequência, severidade, segmento) · citações-âncora · o que é padrão e o
que é caso isolado · demandas candidatas, cada uma com o problema declarado.
