# Opções de crescimento — Ansoff

## Quando usar / quando não

- Use para escolher entre aprofundar no produto/mercado atual e abrir frente nova.
- Não use para priorizar itens dentro de uma frente já escolhida.

## Barra de qualidade

- Cada opção com **a premissa crítica**: o que precisa ser verdade para funcionar.
- Risco cresce ao sair do produto atual e do mercado atual — a comparação explicita isso,
  não trata as opções como equivalentes.
- Cada opção com o menor passo reversível que testa a premissa e quanto custa aprender.
- Sem opção-espantalho para justificar a preferida; caminho único é declarado como único.

## Contrato de output

Opções (aprofundar, novo produto, novo mercado, diversificar) com premissa crítica,
evidência atual e teste mínimo · recomendação · o que faria mudar de ideia.
