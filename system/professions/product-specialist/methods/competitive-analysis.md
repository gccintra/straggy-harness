# Análise competitiva

## Quando usar / quando não

- Use para posicionar, responder objeção de venda ou decidir onde investir em diferencial.
- Não use para copiar backlog de concorrente — paridade de feature não é estratégia.

## Barra de qualidade

- Comparação pelos **critérios de compra do cliente** (jobs), não por lista de features.
- Cada afirmação com fonte e data — concorrente muda, análise vence.
- Separa fato público de suposição; suposição fica marcada.
- Inclui a alternativa não óbvia: planilha, processo manual, não fazer nada.
- Fraqueza própria dita com honestidade; análise em que ganhamos em tudo é propaganda.
- Termina em decisão: o que muda no produto, no preço ou na mensagem.

## Contrato de output

Critérios de comparação · quadro com fonte e data · onde ganhamos, onde perdemos ·
alternativas fora da categoria · decisão recomendada.
