# Planejamento de ciclo

## Quando usar / quando não

- Use ao abrir cada ciclo de entrega.
- Não use para distribuir tarefas nominalmente — quem se organiza é o time.

## Barra de qualidade

- **Meta primeiro, itens depois.** Ciclo sem meta é lista de tarefas e não permite
  negociar escopo depois (`sprint-goal.md`).
- Capacidade real considerada: férias, suporte, incidente, cerimônia. Capacidade nominal é
  ficção.
- O time decide **quanto** cabe; o PO decide **o que** vale mais.
- Item sem critério de aceite não entra.
- Espaço para imprevisto declarado no plano, não improvisado no meio.

## Contrato de output

Meta do ciclo · itens selecionados com o valor de cada um · capacidade considerada ·
dependências e riscos conhecidos.
