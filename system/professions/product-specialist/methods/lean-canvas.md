# Lean / Business Model Canvas

## Quando usar / quando não

- Use para produto novo, linha nova ou pivô — quando o modelo de negócio ainda é hipótese.
- Não use para priorizar backlog de produto existente e estável.

## Barra de qualidade

- Começa por **problema e segmento**, nunca pela solução.
- Vantagem competitiva honesta — "não temos ainda" é resposta válida e mais útil que
  inventar uma.
- Métricas-chave ligadas ao modelo (unidade econômica), não a vaidade.
- Cada bloco com grau de confiança: fato, indício ou chute.
- O canvas é um conjunto de hipóteses. Sair dele com plano em vez de fila de teste é o erro
  clássico.

## Contrato de output

Blocos preenchidos com nível de confiança · as três hipóteses mais arriscadas · teste mais
barato para a mais arriscada.
