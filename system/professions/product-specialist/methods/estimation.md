# Estimativa

## Quando usar / quando não

- Use para sequenciar, negociar escopo e dar previsibilidade de faixa.
- Não use como promessa de data por item, nem como medida de produtividade — estimativa
  usada para cobrar vira estimativa inflada.

## Barra de qualidade

- Estimativa é de **quem executa**, não do PO.
- Relativa e grosseira vence precisa e falsa. Precisão maior que o conhecimento disponível
  é teatro.
- Incerteza alta → **investigação com tempo fixo**, não número maior.
- Velocidade serve para prever o próprio time; comparar times por velocidade é erro de
  leitura.
- Reestimar quando o entendimento muda — nunca para "caber" no plano.

## Contrato de output

Tamanho relativo por item · incerteza declarada (o que faria estourar) · investigação
proposta quando a dúvida domina o número.
