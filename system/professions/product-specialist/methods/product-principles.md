# Princípios de produto

## Quando usar / quando não

- Use quando o mesmo trade-off reaparece em toda decisão e o time discute por gosto.
- Não use para escrever frase de parede — princípio que ninguém discorda não decide nada.

## Barra de qualidade

- Formato com **lado perdedor explícito**: "preferimos A a B, mesmo custando C".
- Extraído de decisões reais já tomadas, não de aspiração.
- Poucos (3 a 5). Lista longa não é consultada.
- Citável como desempate numa discussão concreta — se não desempata nada, corte.
- Revisado quando uma decisão importante o contraria: ou a decisão estava errada, ou o
  princípio está.

## Contrato de output

3 a 5 princípios no formato "preferimos A a B, mesmo quando C" · para cada um, a decisão
real que ele teria resolvido.
