# Teste de usabilidade

## Quando usar / quando não

- Use quando o fluxo é novo, arriscado ou já gera erro em produção, e existe protótipo ou
  tela funcionando.
- Não use para escolher entre variações estéticas — para isso não há tarefa a observar.

## Barra de qualidade

- **Tarefa real**, dita em linguagem de negócio ("registre a vistoria de ontem"), nunca
  instrução de interface ("clique em salvar").
- Sem ajudar durante a tarefa: a hesitação é o dado. Explicar a tela destrói a medição.
- Observa comportamento (onde para, o que tenta, o que erra), não opinião declarada no fim.
- Poucos participantes por rodada, corrigindo entre rodadas, vale mais que uma rodada
  grande.
- Problema classificado por gravidade (impede, atrasa, incomoda) e ligado à tela ou ao
  fluxo específico.

## Contrato de output

Tarefas testadas · participantes (perfil e quantidade) · problemas por gravidade com
evidência · o que muda no protótipo · o que fica para decisão de produto.
