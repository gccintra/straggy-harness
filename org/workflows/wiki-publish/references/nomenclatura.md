# Nomenclatura das páginas de wiki — convenção desta organização

Override do padrão do pack (`system/pack/workflows/wiki-publish/references/nomenclatura.md`).

| Conteúdo | Título | Exemplo |
|---|---|---|
| Módulo do produto | `Módulo — [Nome]` | `Módulo — Gerenciamento de Inscritos` |
| Fluxo | `Fluxo — [Nome]` | `Fluxo — Fechamento de Turma` |
| Changelog | `Changelog — Histórico de Evolução` | página única, append |
| Decisão técnica | `Decisão — [Tema]` | `Decisão — Migração de Paginação` |
| Glossário | `Glossário — [Área]` | `Glossário — Status de Inscrição` |

Título fora da convenção → proponha o ajuste antes de publicar; quem decide é o usuário.
